# 🥊 RECKONING DAY: VOLKOV VS CROSS
### Undisputed World Heavyweight Championship | Official Event Website

A aggressive, high-energy, brutalist PPV combat sports website built with **React**, **Vite**, **Tailwind CSS**, and **Web Audio API**.

---

## ⚡ Key Features

### 1. Aggressive High-Impact Visuals & Audio
- **Atmospheric Particle Engine:** Dynamic HTML5 canvas rendering glowing red (Volkov) and cyan (Cross) embers & sparks.
- **Synthesized Web Audio FX Engine:** Authentic high-resonance boxing bells (🔔), heavy sub-bass punch impacts (💥), tactical UI clicks, and cash payouts with zero external audio latency. Sound FX toggle included in header.
- **Brutalist Poster Typography:** Teko, Barlow Condensed, Bebas Neue, and Rajdhani typography with neon text-glow and octagon cage mesh patterns.
- **Live Countdown Timer:** Real-time ticking countdown to fight night at The Sphere, Las Vegas.

### 2. Tale of the Tape & Combat Intelligence
- **Head-to-Head Physical Metrics:** Height, weight, reach (80.5" vs 82.0"), leg reach, stance, finishing rate, and age comparison with visual advantage indicators.
- **Combat Attribute Meters (1-100):** Striking Power, Hand Speed, Chin Durability, Grappling & Subs, Cardio Stamina, Brutality Index, and Takedown Defense.
- **Fighter Dossiers:** Switch between Viktor Volkov and Damian Cross to inspect bios, quotes, signature maneuvers, tactical advantages, and recent knockout fight histories.

### 3. Interactive Ticket Booking System
- **Interactive Arena Schematic Map:** Clickable zones (Octagon Cage-Side VIP, Floor Champions, Lower Bowl, Bleachers, 4K PPV Pass) that highlight seating locations and sightlines.
- **Reservation Modal & Pricing Engine:** Choose seat quantities, add collector memorabilia (signed glove & weigh-in pass), Nevada live entertainment tax calculation, and payment source (Combat Credits, Card, or Crypto).
- **Holographic Digital VIP Pass Generator:** Instantly renders a security pass with custom ticket number, seat assignment, barcode, QR code, gate directions, and print/download pass functionality with victory confetti.

### 4. Official Sportsbook & Live Fight Betting
- **Multiple Betting Markets:**
  - **Championship Moneyline:** Viktor Volkov (-130) vs Damian Cross (+110)
  - **Method of Victory:** KO/TKO, Submission, Decision, or Draw (+4500)
  - **Round Props:** Round 1 KO, Round 2 Finish, Over/Under 1.5 Rounds, Distance
  - **Carnage Specials:** First round knockdowns, blood cuts, spinning strikes
- **Interactive Betslip Drawer:**
  - Real-time American & Decimal odds payout calculator (Stake + Profit).
  - Quick wager chips ($50, $100, $250).
  - Simulated **$1,000 Combat Credits Bankroll** with instant reset & top-up capability.
  - Active Bets tracker with official ticket numbers.
- **Interactive Cage Fight Simulator:**
  - Simulate the 5-round championship bout live!
  - 3-phase round-by-round commentary with sound effects and dramatic referee stoppage.
  - Automatically grades all user's active bets as WON / LOST and credits winning payouts directly back into your bankroll!

### 5. Full Undercard & Fan Hype Features
- **Co-Main Event & Feature Bouts:** Marcus Silva vs Kenji Takahashi, Elena Rostova vs Sarah Vance, Jaxson Brooks vs Bojan Radic with odds and direct betting shortcuts.
- **Live Fan Consensus Prediction Poll:** Vote between Volkov and Cross to see dynamic real-time percentage bars and vote totals.
- **Press Conference Quotes Marquee:** Fiery soundbites from the London & Vegas media days.

## 🚀 How to Run

### Development Server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build:
```bash
npm run build
npm run preview
```
Or directly open `dist/index.html` in any modern web browser.
